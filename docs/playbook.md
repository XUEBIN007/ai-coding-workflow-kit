# MVP 作战手册

## 产品一句话

帮大陆开发者和小团队，用国内可用模型搭建一套接近 Codex 的 AI 编程工作流。

## 不做什么

- 不卖 OpenAI 账号。
- 不做代理或中转 API。
- 不承诺绕过地区限制。
- 不让 AI 自动提交、自动部署或直接改生产配置。

## 首批目标用户

- 想用 Codex / Claude Code 但访问或支付不稳定的大陆开发者。
- 5-20 人的软件外包团队。
- 使用 Gitee、GitLab、GitHub 的小型研发团队。
- 需要把老项目文档化、测试补齐、bug 修复提效的团队。

## MVP 验证指标

- 50 个意向线索。
- 5 个真实内测用户。
- 10 个真实开发场景案例。
- 1 个团队试点。

## 交付结构

1. 环境搭建：VS Code、Roo Code、Qwen Code。
2. 模型接入：DeepSeek、Qwen、OpenAI-compatible、本地模型。
3. 项目规则：代码风格、测试命令、禁止事项、输出格式。
4. 私有知识库：项目文档、接口文档、需求文档、FAQ。
5. Git 工作流：issue、改动计划、diff review、PR/MR。
6. 安全检查：密钥、敏感文件、权限、日志、部署边界。

## 第一个公开 Demo

场景：一个已有 Web 项目存在 bug。

流程：

1. 让 AI 阅读 README 和关键源码。
2. 让 AI 解释 bug 可能位置。
3. 让 AI 制定最小修改计划。
4. 执行修改。
5. 运行测试。
6. 查看 diff。
7. 写 PR 描述。

## 内容发布节奏

- 第 1 篇：国内可用的 Codex 替代工作流。
- 第 2 篇：Roo Code + DeepSeek 从 0 搭建。
- 第 3 篇：Qwen Code + Git 仓库实战。
- 第 4 篇：AI 编程安全边界。

## 定价假设

- 入门包：99-199 RMB。
- 进阶小班：499-999 RMB。
- 团队落地：3000-10000 RMB。
- 企业 PoC：30000 RMB 起。
