MVP Kit

第一版只解决一件事：让用户跑起来。

模型接入

DeepSeek、Qwen、OpenAI-compatible、本地模型。按任务给出推荐组合。

Agent 工具

Roo Code 负责 VS Code 内改代码，Qwen Code 负责终端任务和仓库级操作。

私有知识库

把 README、接口文档、需求文档、FAQ 放进 FastGPT 或同类 RAG 工具。

安全规范

禁止自动提交、禁止改生产配置、敏感文件黑名单、人工 review 必经。

Daily Workflow

把 AI 编程变成一个可重复流程。

  1. 建立项目规则 写入技术栈、代码风格、测试命令、禁止事项。
  2. 连接模型与仓库 Roo Code / Qwen Code 接 DeepSeek 或 Qwen，仓库接 GitHub、Gitee 或 GitLab。
  3. 让 AI 先读再改 先总结代码、列计划、确认风险，再允许局部修改。
  4. 测试与审查 运行本地测试，查看 diff，人工合并 PR/MR。

90-Day Plan

从可爱 MVP 到能收费的落地包。

01

需求验证

发布长文、短视频、演示页，收集 50 个线索和 5 个愿意试用的人。

02

模板打磨

补齐 DeepSeek/Qwen 配置、常见错误、10 个真实开发案例。

03

小班交付

带 5-10 个开发者完成配置，记录卡点，形成 FAQ。

04

团队试点

面向外包团队、SaaS 小团队、跨境业务技术团队做远程落地。
